# 프롬프트 워크벤치

드랍다운을 위에서부터 차례로 고르면 분야별 전문 용어로 정리된 AI 지시문(프롬프트)이 자동으로 완성되는 대시보드입니다.

## 실행 방법
- `index.html`을 브라우저(크롬/엣지)로 바로 열면 됩니다. 서버·설치 필요 없음.
- 원본은 `src/app.html`이고, 수정 후 `./build.sh`를 실행하면 `index.html`이 다시 만들어집니다.

## 동작 방식
1. **순차 잠금**: 위 단계를 고르기 전에는 아래 단계가 잠겨 있고, 다음에 고를 칸이 파란 점으로 표시됩니다.
2. **연동 드랍다운**: '세부 항목'을 바꾸면 '수행 작업', '핵심 지표', '피사체' 같은 하위 목록이 그에 맞게 바뀝니다.
3. **용어 설명**: 고른 값에 RPN, FPY, 돌리 인, 림 라이트 같은 전문 용어가 있으면 옆 칸에 뜻이 표시됩니다.
4. **영문 생성 프롬프트**: 영상·사진·음성 탭은 선택지마다 영문 표현이 붙어 있어 Midjourney(`--ar --v 7 --no`), Stable Diffusion(Negative prompt), Sora/Veo, Suno 형식에 맞는 영문 프롬프트가 함께 만들어집니다.
5. **프롬프트 형식**: 마크다운 섹션 / XML 태그(Claude 권장) / 한 문단 요약형 중 선택.
6. **직접 추가**: 모든 드랍다운 맨 아래 '＋ 직접 추가…'로 나만의 선택지를 넣을 수 있습니다(브라우저에 저장).

## 히스토리 학습 (내 의도 반영)
대화 기록 파일을 올리면 내가 보낸 메시지만 골라 분석합니다. 분석은 브라우저 안에서만 이뤄집니다.
- 지원 형식: Claude Code `*.jsonl`, VS Code Copilot `chatSessions/*.json`, Claude.ai·ChatGPT `conversations.json`, Gemini 테이크아웃 `MyActivity.json`, 일반 텍스트
- 결과
  - **자주 쓴 용어** → 드랍다운 맨 위로 ★ 표시되어 올라옴
  - **반복 지시 문장**(예: "한글로 설명해줘") → '규칙으로' 버튼으로 기본 규칙에 등록
  - **'내 패턴으로 빈칸 채우기'** 버튼 → 비어 있는 칸을 자주 쓴 값으로 자동 선택
- 기본 규칙에는 처음부터 다음 3가지가 켜져 있습니다: 질문→계획→승인 후 진행 / DB 저장 시 영문은 한글로 번역 / 설명은 한글로

### 기록 파일 위치
- Claude Code: `~/.claude/projects/<프로젝트>/*.jsonl`
- VS Code Copilot Chat: `%APPDATA%\Code\User\workspaceStorage\<id>\chatSessions\*.json`
- Claude.ai: 설정 → 개인정보 → 데이터 내보내기
- ChatGPT: 설정 → 데이터 제어 → 데이터 내보내기
- Gemini: Google 테이크아웃 → 내 활동

## 선택지 수정
`src/app.html`의 `TABS` 배열에서 탭·항목·선택지를 고칩니다.
- `o: [...]` 선택지 목록, `o: {상위값: [...], '*': [...]}` 상위 항목에 따라 바뀌는 목록
- `dep: 'sub'` 연동할 상위 항목, `multi: true` 다중 선택, `opt: true` 선택 사항
- `'한글 | English'` 형식으로 쓰면 영문은 생성용 프롬프트에만 사용
